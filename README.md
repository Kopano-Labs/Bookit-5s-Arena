## What Is This

Bookit 5s Arena is the **booking engine** for FivesArena — five-a-side football venue management, player coordination, and match scheduling.

An **Adaptive PWA** — works offline for venue check-in, adapts by role (player/manager/venue owner), and compresses UI during live matches.

## APWA Standard

| # | Dimension | Implementation |
|---|-----------|---------------|
| 1 | **Connectivity** | Offline booking confirmation · Sync when connected |
| 2 | **Role** | Player · Team captain · Venue owner · Admin |
| 3 | **Urgency** | Standard browse → match day → tournament mode |
| 4 | **Device** | Mobile-first · QR check-in kiosk |
| 5 | **Trust** | Verified venues · Player ratings · Payment confirmation |
| 6 | **Local Context** | City · Venue · League · Time zone |
